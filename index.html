TikTok Quality Uploader

A Chromium browser extension that uploads a video file to the user's own TikTok inbox through TikTok's official Content Posting API, sending the original file unchanged (no re-encoding or compression).

How it works

  1. The user connects their TikTok account with TikTok Login Kit (desktop flow with PKCE) and grants the video.upload permission.
  2. The user selects a video file. The extension analyses it locally and computes a SHA-256 checksum.
  3. The file is sent to TikTok in chunks using the official upload endpoint. Each chunk is verified against the checksum before it is sent.
  4. The video appears as a draft in the user's TikTok inbox; the user finishes and publishes the post inside the TikTok app.

This project is independent and is not affiliated with or endorsed by TikTok.
